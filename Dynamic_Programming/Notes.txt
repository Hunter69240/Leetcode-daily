Pattern 1: 1D Linear DP
When to use: Current value depends on 1-2 previous values, moving forward
Problems: LC 70 (Climbing Stairs), LC 746 (Min Cost Stairs), LC 198 (House Robber), LC 213 (House Robber II), LC 322 (Coin Change)
Key idea: dp[i] = some function of dp[i-1] and/or dp[i-2]
Recognition: "how many ways", "min/max cost to reach end", moving left to right, no skipping rows

Pattern 2: Grid DP
When to use: Moving through a 2D grid, usually top-left to bottom-right
Problems: LC 62 (Unique Paths), LC 63 (Unique Paths II), LC 64 (Min Path Sum), LC 119 (Pascal's Triangle)
Key idea: dp[i][j] = dp[i-1][j] + dp[i][j-1] (or min/max variant)
Recognition: grid input, can only move right/down, count paths or find min cost

Pattern 3: 2D DP on Triangle/Matrix
When to use: Falling through rows, each cell depends on adjacent cells in previous row
Problems: LC 120 (Triangle), LC 931 (Min Falling Path Sum)
Key idea: for each cell, take min of valid neighbors above + current value
Recognition: triangle or square matrix, top to bottom, answer is min of last row
Difference: Triangle edges have 1 neighbor (grid narrows), Falling Path edges have 2 (grid is rectangular)

Pattern 4: Knapsack / Subset DP
When to use: Can you pick elements that sum to a target? Include or exclude each element
Problems: LC 416 (Partition Equal Subset Sum)
Key idea: dp[i][j] = can we make sum j using first i elements
Recognition: "can you partition", "subset that sums to X", binary include/exclude decision

Pattern 5: Sequential String DP
When to use: Moving forward through a string, current state depends on previous 1-2 positions
Problems: LC 91 (Decode Ways)
Key idea: dp[i] = ways to decode s[:i], depends on single digit and two digit combos
Recognition: string input, counting ways to parse/split/decode, no skipping characters

Pattern 6: Interval DP (Corners Inward)
When to use: Working on a substring window [i,j], shrinking inward, can skip characters
Problems: LC 516 (Longest Palindromic Subsequence)
Key idea: if s[i]==s[j]: 2 + solve(i+1, j-1), else: max(solve(i+1,j), solve(i,j-1))
Base cases: i > j → 0, i == j → 1
Recognition: "longest palindromic subsequence", choices at both ends, subsequence = can skip

Pattern 7: Center Expand (Not DP, but string)
When to use: Finding/counting palindrome substrings, contiguous only, no skipping
Problems: LC 647 (Palindromic Substrings)
Key idea: every palindrome has a center, expand outward while both sides match
Must check both odd center (i,i) and even center (i,i+1)
Recognition: "palindrome substrings", contiguous characters, count or find all

Pattern 8: Sliding Window
When to use: Contiguous subarray/substring with some condition, window expands and shrinks
Problems: LC 643 (Max Average Subarray), LC 340, LC 904
Key idea: right pointer expands, left pointer shrinks when condition breaks
Recognition: "contiguous subarray", fixed or variable window size, no skipping

Pattern 9: Greedy
When to use: Local optimal choice leads to global optimal, no need to explore all options
Problems: LC 45 (Jump Game II), LC 55 (Jump Game)
Key idea: at each step take the best available move, trust it leads to optimal
Recognition: "minimum jumps", "can you reach end", making range-based decisions

## Decision Tree — String / Palindrome Problems only
## For all other patterns, use input type as first signal

Given a string/palindrome problem:
Can I skip characters? (subsequence)
  YES → Interval DP, Pattern 6
  NO  → Am I finding palindrome substrings?
            YES → Center Expand, Pattern 7
            NO  → Is there a variable window condition?
                      YES → Sliding Window, Pattern 8
                      NO  → Sequential String DP, Pattern 5

## For non-string problems use input type:
Array of numbers → Pattern 1, 4, or 9
Grid/Matrix → Pattern 2 or 3
